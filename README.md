# Gerenciador de Tarefas (Java - CLI)

Projeto iniciante em Java para treinar entrada de dados, estruturas de decisão, loops e listas usando `ArrayList`.

## Funcionalidades
- **1**: Adicionar tarefa
- **2**: Listar tarefas
- **3**: Sair

## Como rodar (IntelliJ)
1. Abra o projeto no IntelliJ.
2. Execute o arquivo `Main.java` (botão ▶).
3. Use o menu no console para interagir.

## Exemplo de uso
- Digite `1` e escreva uma tarefa
- Digite `2` para listar as tarefas
- Digite `3` para sair

## Tecnologias
- Java
- IntelliJ IDEA
